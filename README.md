# Blur Nav Test

Тестовый APK: нижний навбар с прогрессивным блюром и лёгким цветом навбара (как в прототипе v19), на Haze 1.7.2 + Jetpack Compose.

## Как получить APK
0. (Необязательно) добавь в Settings → Secrets and variables → Actions четыре секрета: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Без них workflow подпишет APK временным ключом, и он всё равно установится.
1. Создай репозиторий на GitHub, залей содержимое этого архива в корень (ветка `main`).
2. Открой вкладку **Actions**, workflow **Build release APK** запустится сам (или нажми *Run workflow*).
3. Когда он позеленеет, открой запуск и скачай артефакт **blurnav-release-apk**: это ZIP, распакуй его и ставь `app-release.apk` (подписанный, собран с R8).
4. Установи на телефон (разреши установку из неизвестных источников).

## Что в приложении
Сверху три режима: **Progressive** (настоящий прогрессивный блюр), **Mask** (дешёвая альтернатива через маску), **Off** (без блюра, для сравнения плавности). Ползунки: радиус блюра, насколько блюр выше навбара, сила цвета навбара в блюре.

## Если сборка упала
- Версии в `build.gradle.kts` / `app/build.gradle.kts` (AGP 8.13.0, Kotlin 2.2.20, Compose BOM 2025.10.01, Haze 1.7.2) подобраны по документации, но у меня не было возможности собрать проект. Пришли лог упавшего шага, поправим.
- Haze 2.0.x (вышел 22.09.2026) требует Kotlin 2.4.x и другой API (`hazeBlur`, `HazeBlurStyle`); перейти можно отдельным шагом.
